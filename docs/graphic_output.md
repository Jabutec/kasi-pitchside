# Kasi Pitchside — Graphic / Output Spec

## Brand basics

- Background: white (`#FFFFFF`)
- Text/accent color: dark green — **`#2B523F`** (sampled directly from the Kasi Pitchside logo background)
- Font: Montserrat (Regular, Medium, SemiBold `.ttf` files ready)
- No bold — hierarchy comes from **size** and **weight variant** instead:
  - Headings: Montserrat SemiBold
  - Subheadings / labels: Montserrat Medium
  - Body / data text: Montserrat Regular
- Logo: Kasi Pitchside logo, fixed position and size (see Layout below)

## Type scale

| Level       | Use case                         | Size    | Weight   |
| ----------- | -------------------------------- | ------- | -------- |
| Heading     | "MATCHDAY", graphic title        | 64-72pt | SemiBold |
| Subheading  | Team names, stat category labels | 32-36pt | Medium   |
| Body / data | Scores, dates, stat numbers      | 22-26pt | Regular  |
| Footer      | Source credit, date generated    | 14-16pt | Regular  |

## Canvas sizes (per platform)

| Platform / placement               | Dimensions | Notes                                     |
| ---------------------------------- | ---------- | ----------------------------------------- |
| Instagram/Facebook feed (square)   | 1080×1080  | Primary format — matches reference layout |
| Instagram/Facebook feed (portrait) | 1080×1350  | More vertical space for longer stat lists |
| Instagram/TikTok story             | 1080×1920  | For story reposts of feed graphics        |
| Twitter/X                          | 1080x1080  | Primary format                            |

Start with the square (1080×1080) as the primary rendered size; other sizes can be generated by re-flowing the same layout config later.

## Layout grid

- Safe margin: 60-80px from every edge — logo, text, and badges never touch the canvas edge
- Logo placement: fixed position (e.g. top-right, matching FarPost/Betway reference), fixed size relative to canvas, consistent across every graphic type
- Divider/accent element: vertical green line as a recurring anchor (used next to headings like "MATCHDAY") — decide whether this is a permanent element across all graphic types or specific to matchday-style posts

## Data-driven layout rules (for automation)

- **Long names** (e.g. "Lamontville Golden Arrows"): auto-shrink font size or wrap to a second line — define one consistent rule, don't mix both
- **Null/zero stats** (e.g. 0 assists): still render "0", don't omit the row
- **Fewer than N items available** (e.g. "last 5 games" early in the season): render what's available and label it accurately (e.g. "Last 3 games" instead of forcing "Last 5")
- **Missing player/team image**: fall back to a placeholder badge/silhouette rather than leaving blank space

## File output

- Format: PNG (transparent-safe, no compression artifacts)
- Naming convention: `{graphic_type}_{team_or_matchday}_{date}.png`
  - e.g. `matchday_wk3_2026-08-26.png`, `h2h_chiefs-vs-pirates_2026-08-26.png`
- Naming convention prevents overwrites and keeps automated output organized without manual renaming

## Locked assets

- Montserrat Regular, Medium, SemiBold `.ttf` files
- Kasi Pitchside logo: transparent-background PNG (black pitch-mic icon mark), 512×512 working size — resize per canvas placement rules above
